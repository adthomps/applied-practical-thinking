CRT World is the live author site for C. R. Thompson, The Worlds of C. R. Thompson. Visitors can discover the author's worlds on the public site.

The same Cloudflare app serves that public site and the editorial admin. A Worker API and a D1 database hold the published content. This is a real site, not a mock.
